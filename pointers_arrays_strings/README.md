# Pointers, Arrays and Strings

## Task 0: 98 Battery st.

This task implements a function that updates the value of an integer to 98 using a pointer.

### Prototype

void reset_to_98(int *n);

### Description

The function takes a pointer to an integer as a parameter and changes the value stored at the memory address pointed to by the pointer to 98.

### Example

If n is initially 402, after calling reset_to_98(&n), its value becomes 98.

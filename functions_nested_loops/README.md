# C - Functions, nested loops

This project covers functions and nested loops in C.

## Learning Objectives
- Nested loops
- Functions
- Function prototypes
- Scope of variables
- Header files

## Tasks
- 0. _putchar

## Task 1: print_alphabet

A function that prints the lowercase English alphabet followed by a new line.

## Task 2: 10 x alphabet

A function that prints the lowercase alphabet 10 times, each on a new line.

## Task 3: islower

A function that checks whether a character is lowercase.
Returns 1 if lowercase and 0 otherwise.

## Task 4: isalpha

A function that checks whether a character is an alphabetic letter.
Returns 1 for uppercase and lowercase letters, and 0 otherwise.

## Task 5: Sign

A function that prints the sign of a number.
Returns 1 for positive numbers, 0 for zero, and -1 for negative numbers.

## Task 6: Absolute Value

A function that computes the absolute value of an integer.
Negative numbers become positive, while positive numbers and zero remain unchanged.

## Task 7: Print Last Digit

A function that prints the last digit of an integer and returns its value.
The last digit is always printed as a nonnegative digit.

## Task 8: 24 Hours

A function that prints every minute of the day, from 00:00 to 23:59.
Uses nested loops to iterate through 24 hours and 60 minutes.

## Task 9: Times Table

A function that prints the 9 times table, starting from 0.
Uses nested loops to calculate and display multiplication results.

## Task 10: Add

A function that adds two integers and returns their sum.

## Task 11: Print to 98

A function that prints all integers from a given number to 98.
It counts upward when the starting number is less than 98,
and downward when it is greater than 98.
Numbers are separated by a comma and a space.

## Task 12: 100 Times Table

A function that prints the multiplication table of n, starting from 0.
The function accepts values from 0 to 15 only.
It uses nested loops and formats the output with commas and spaces.
